# 🤖 Smart Office CRM

### Automation Using Python and React JS

Smart Office CRM is an automation-based office management application developed to simplify **manpower management and task delegation**.

The project uses **React JS** for the frontend user interface and **Python** for automation and processing. It helps organize employee information, create and assign tasks, and reduce repetitive manual work.

---

## 📌 Project Overview

Managing employees, assigning tasks, and monitoring work manually can take significant time and effort.

Smart Office CRM provides an organized workflow for:

- 👥 Manpower Management
- 📝 Task Creation
- 📌 Task Assignment
- 📊 Task Management
- ⚙️ Python-based Automation
- 🖥️ Interactive React JS Interface

---

## 🎯 Objectives

- Develop an automated office management application.
- Manage manpower information in an organized manner.
- Simplify task delegation.
- Reduce repetitive manual work.
- Provide an easy-to-use user interface.
- Use Python for automation-related operations.
- Use React JS for frontend development.
- Improve task organization and monitoring.
- Reduce errors in manual task allocation.
